# PARTS//DRIVE — сайт подбора и доставки автозапчастей

Одностраничный премиальный сайт с 3D-историей «поломка → поиск → доставка → замена»,
рентген-режимом автомобиля под курсором и заявками в Telegram.

## Что внутри

| Часть | Где |
|---|---|
| Все тексты, бренд, контакты, категории, марки, FAQ | `src/config/site.ts` |
| Цвета, шрифты, отступы (дизайн-система) | `src/styles/global.css` (переменные в `:root`) |
| 3D-модель машины с внутренним макетом | `src/components/3d/carFactory.ts` |
| Сюжет прокрутки (камера, деталь, линза) | `src/components/3d/StoryScene.tsx`, `src/components/sections/StorySection.tsx` |
| Рентген-секция | `src/components/3d/AnatomyScene.tsx`, `src/components/sections/Anatomy.tsx` |
| Форма заявки | `src/components/forms/LeadForm.tsx`, `src/lib/lead.tsx` |
| Приём заявок, Telegram, антиспам, резервное хранение | `server/lib/lead.mjs` |
| Функции для Vercel | `api/lead.js`, `api/retry-leads.js`, `vercel.json` |
| Свой сервер (VPS) | `server/index.mjs` |
| Шаблоны юридических страниц | `public/privacy.html`, `public/personal-data.html` |

Стек: React 19 + TypeScript + Vite, Three.js + React Three Fiber + Drei, Zod.
3D загружается отдельным чанком только когда нужен; без WebGL показывается векторная схема,
на телефонах и слабых устройствах включается облегчённый режим, `prefers-reduced-motion` учитывается.
Режим можно принудительно проверить: `?mode=full`, `?mode=lite`, `?mode=static`.

## Запуск

```bash
npm install
cp .env.example .env      # заполните TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
npm run dev               # http://localhost:5173 — сайт + API заявок
npm run build             # проверка TypeScript и сборка в dist/
npm start                 # продакшен-сервер: dist/ + /api/lead на PORT (по умолчанию 3000)
```

Нужен Node.js 20 или новее.

## Переменные окружения

| Переменная | Обязательно | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен бота от @BotFather — только на сервере |
| `TELEGRAM_CHAT_ID` | да | куда приходят заявки: ваш ID, группа или канал |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | для Vercel — да | надёжное хранение заявок, если Telegram недоступен, и общий лимит частоты |
| `CRON_SECRET` | для Vercel | защищает `/api/retry-leads` (досылка отложенных заявок) |
| `LEADS_DIR` | нет | папка резервного хранения на своём сервере (по умолчанию `./.data/leads`) |
| `PORT` | нет | порт сервера |
| `VITE_LEAD_ENDPOINT` | нет | если API живёт на другом домене: полный URL до `/api/lead` (задаётся при сборке) |

Токен бота никогда не попадает во фронтенд: в браузер уходит только адрес `/api/lead`.

## Подключение Telegram

**Сейчас (без бота).** В `src/config/site.ts` стоит `LEAD_DELIVERY = 'telegram-link'`: после заполнения формы у клиента открывается
чат с `contacts.telegram` (@Maks_Sypachev) с готовым текстом заявки, ему остаётся нажать «Отправить». Сервер для этого не нужен.

**С ботом (заявки приходят автоматически).** Создайте бота по шагам ниже, задайте переменные окружения и поменяйте
`LEAD_DELIVERY` на `'bot'`.

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя и username. Скопируйте токен — это `TELEGRAM_BOT_TOKEN`.
2. Напишите своему боту любое сообщение (иначе он не сможет вам писать).
   Для группы: добавьте бота в группу и напишите в ней сообщение.
3. Узнайте chat ID: откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`.
   Личный ID — положительное число, у группы — отрицательное (часто начинается с `-100`). Это `TELEGRAM_CHAT_ID`.
4. Впишите обе переменные в `.env` (локально/VPS) или в настройки проекта на Vercel.
5. Отправьте тестовую заявку с сайта — она придёт с кнопкой быстрого перехода к контакту клиента.

Что происходит при сбое: сервер делает до 3 попыток с тайм-аутом 8 с (учитывая `retry_after` от Telegram).
Если доставка не удалась — заявка сохраняется (Upstash Redis или файл на своём сервере), клиент видит
честное «принята и сохранена», а досылка идёт по крону (Vercel) или каждые 5 минут (свой сервер).
Если сохранить тоже не удалось — клиент видит ошибку, а его данные остаются в форме.

Антиспам: скрытое поле-ловушка, минимальное время заполнения, лимит 5 заявок за 10 минут с одного IP,
защита от двойной отправки, ограничение длины полей, экранирование HTML в сообщении.

## Публикация на Vercel

1. Загрузите проект в GitHub-репозиторий.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → выберите репозиторий. Настройки сборки подхватятся из `vercel.json`.
3. **Settings → Environment Variables**: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `CRON_SECRET` (любая длинная случайная строка).
   Upstash: [upstash.com](https://upstash.com) → создайте Redis-базу → вкладка REST API → URL и токен.
4. **Deploy**. Подключите свой домен в **Settings → Domains**.

Крон досылки настроен раз в сутки (ограничение бесплатного плана Vercel); на платном плане можно
поставить чаще в `vercel.json`.

Альтернатива для аудитории в России — свой VPS у российского хостера: `npm ci && npm run build && npm start`
за nginx с HTTPS (или через pm2/systemd). Резервные заявки сохраняются в `LEADS_DIR`.

## Замена 3D-модели

Сейчас используется процедурная демонстрационная модель кроссовера (подписана на сайте как демонстрационная).
Чтобы поставить настоящую модель (GLB/GLTF с подходящей лицензией):
1. Положите файл в `public/models/` и загрузите его через `useGLTF` из Drei.
2. Материалы кузова пропустите через `patchBodyMaterial` из `src/components/3d/lens.ts` — так заработает рентген-линза.
3. Узлы внутреннего макета пометьте `userData.partId` (список — `src/components/3d/parts.ts`), сюжетную деталь — отдельным объектом.

## Что нужно заполнить вашими данными

- `src/config/site.ts`: название бренда (`brand`), контакты (`contacts.telegram`, `phone`, `email`, `city`, `legal`) — пустые поля на сайте не показываются.
- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (и Upstash + `CRON_SECRET` для Vercel).
- `public/privacy.html` и `public/personal-data.html`: данные оператора в отмеченных полях, текст согласовать с юристом.
- Домен и, при желании, OG-картинка/описание в `index.html`.
- Настоящая 3D-модель (по желанию) — см. выше.
- Сроки, цены, гарантии и отзывы на сайте специально не указаны — добавляйте только подтверждённые данные.
